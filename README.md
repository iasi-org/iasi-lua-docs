# iasi-lua-docs

Documentation for the Lua extensions distributed by the IASI ecosystem.

Publications:

- `01-user-guide/` — installation, configuration, usage, and troubleshooting.

Each Quarto project publishes into its own `publish/` directory. The GitHub
Pages workflow discovers every `*/publish/index.html`, places each publication
under its project path, and generates a repository-level documentation index.
